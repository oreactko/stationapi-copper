# Copper (Station API)

Copper is a mod for Minecraft Beta 1.7.3 to add copper like in Minecraft 1.21.9
It is built for the Babric modding environment and uses Station API.

## Requirements

- Minecraft Beta 1.7.3
- A Babric-compatible instance
- Babric Loader for Beta 1.7.3
- Station API for Beta 1.7.3
- Java 17 or newer

Do not use a modern Minecraft instance or a regular Fabric Loader instance.
Babric and Station API are separate from modern Fabric versions.

## Installation

1. Install a Babric-compatible launcher, such as [Prism Launcher](https://prismlauncher.org/).
2. Create a new Minecraft Beta 1.7.3 instance using the Babric instructions:
   [Babric Installation](https://babric.github.io/).
3. Add the required [Station API](https://github.com/ModificationStation/StationAPI)
   release for Beta 1.7.3 to the instance's `mods` folder. The project was
   developed against Station API `2.0.0-alpha.6.4`.
4. Download the latest Copper jar from the project's
   [GitHub Releases](https://github.com/oreactko/stationapi-copper/releases) page or from [Modrinth](https://modrinth.com/mod/stationapi-copper).
5. Copy the downloaded `stationapi_copper-*.jar` into the same `mods` folder or
   use the "Add Mod" feature of your launcher to add it to the instance.
6. Launch the instance.

## Troubleshooting

- Confirm that the instance is Minecraft Beta 1.7.3 and uses Babric.
- Confirm that Station API and Copper are both in the instance's `mods` folder.
- Remove duplicate or older Copper and Station API jars before retrying.
- Use Java 17 or newer if the launcher reports an unsupported Java version.
- Check the [Station API wiki](https://github.com/ModificationStation/StationAPI/wiki)
  and the [Babric documentation](https://babric.github.io/) for loader-specific
  problems.
